# IEB Physical Sciences · Grade 11 每日一练

Grade 11 Physical Sciences（IEB）复习材料：物理 P1 与化学 P2 交替，共 24 天。每天一张 A4（正面讲解 + 图解，反面练习），另附答案页、公式总表、必背定义。

- 在线浏览：GitHub Pages（见仓库 About）
- 打印：在任意页面点“打印 / 存 PDF”，选择 A4、双面打印、关闭页眉页脚
- 修改内容：编辑 `src/content_phys.py`、`src/content_chem.py`、`src/figs.py`，然后运行 `python3 src/build.py`

常数与符号按 IEB Grade 11 data sheet（g = 9,8 m·s⁻²；v_i、v_f、Δx、Δt）。所有题目均为原创练习题。
