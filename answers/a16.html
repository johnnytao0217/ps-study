✏️ 练习

  1. 16.1　(4 分)
    (a) n = 11/44 ✓ = 0,25 mol ✓　(b) N = 0,25 × 6,02 × 10²³ ✓ = 1,51 × 10²³ 个分子 ✓
  2. 16.2　(2 分)
    V = nVm = 0,15 × 22,4 ✓ = 3,36 dm³ ✓
  3. 16.3　(4 分)
    n = cV = 0,2 × 0,25 ✓ = 0,05 mol ✓；m = nM = 0,05 × 40 ✓ = 2,00 g ✓
