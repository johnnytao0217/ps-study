每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　x = 6
  2. W2　Δt = Δv / a

✏️ 练习

  1. 5.1　(4 分)
    v = 0 + 3(6) ✓ = 18 m·s−1 ✓；Δx = 0 + ½(3)(6)2 ✓ = 54 m ✓
  2. 5.2　(3 分)
    v2 = u2 + 2aΔx：0 = 302 + 2a(75) ✓✓ → a = −6 m·s−2，大小 6 m·s−2 ✓
  3. 5.3　(3 分)
    Δx = ((v + u)/2)Δt：42 = (14/2)Δt ✓✓ → Δt = 6 s ✓
  4. 5.4　(5 分)
    反应距离 = 20 × 0,5 = 10 m ✓✓；刹车：0 = 202 + 2(−5)Δx ✓ → Δx = 40 m ✓；总距离 50 m ✓
  5. 5.5　(6 分)
    设警车用时 t：警车 Δx = ½(4)t2 = 2t2 ✓；超速车 Δx = 20(t + 3) ✓；令相等：2t2 = 20t + 60 ✓ → t2 − 10t − 30 = 0 ✓
    t = (10 + √220)/2 = 12,42 s ✓；距离 = 2(12,42)2 ≈ 308,32 m ✓
