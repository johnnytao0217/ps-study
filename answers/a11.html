Day 11物理 P1答案与评分点共 20 分

每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　sin30° = 0,50；cos30° = 0,87
  2. W2　w = 5 × 9,8 = 49 N

✏️ 练习

  1. 11.1　(4 分)
    w∥ = 3(9,8)sin30° ✓ = 14,70 N ✓；w⊥ = 3(9,8)cos30° ✓ = 25,46 N ✓
  2. 11.2　(2 分)
    (a) fs = 14,70 N（沿斜面向上） ✓　(b) N = 25,46 N ✓
  3. 11.3　(5 分)
    w∥ = 6(9,8)sin25° = 24,85 N ✓；N = 6(9,8)cos25° = 53,29 N ✓；fk = 0,2 × 53,29 = 10,66 N ✓；24,85 − 10,66 = 6a ✓ → a = 2,37 m·s⁻² 沿斜面向下 ✓
  4. 11.4　(3 分)
    N = mg cosθ 减小 ✓；fs = mg sinθ 增大 ✓；因为 θ 增大时 cosθ 减小、sinθ 增大 ✓
  5. 11.5　(6 分)
    受力图：F 沿斜面向上，w 向下，N 垂直斜面，f 沿斜面向下 ✓；匀速 → Fnet = 0 ✓；w∥ = 2(9,8)sin20° = 6,70 N ✓；fk = 0,25 × 2(9,8)cos20° = 4,60 N ✓；F = 6,70 + 4,60 ✓ = 11,31 N ✓
