Day 09物理 P1答案与评分点共 22 分

每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　w = 50 × 9,8 = 490 N
  2. W2　1 N = 1 kg·m·s−2

✏️ 练习

  1. 9.1　(2 分)
    a = Fnet/m = 12/4 ✓ = 3 m·s−2 ✓（方向与合力相同）
  2. 9.2　(2 分)
    向下的重力 w / Fg ✓；向上的法向力 N ✓（两箭头等长）
  3. 9.3　(7 分)
    (a) N = mg = 10 × 9,8 ✓ = 98 N ✓
    (b) fk = μkN = 0,3 × 98 ✓ = 29,4 N ✓
    (c) Fnet = ma：50 − 29,4 = 10a ✓✓ → a = 2,06 m·s−2 ✓
  4. 9.4　(11 分)
    (a) w 向下、N 向上、F 斜向上 30°、f 与运动方向相反 ✓✓✓✓
    (b) N + F sin30° = mg ✓ → N = 98 − 25 ✓ = 73 N ✓
    (c) fk = 0,3 × 73 = 21,9 N ✓；F cos30° = 43,30 N ✓；43,30 − 21,9 = 10a ✓ → a = 2,14 m·s−2 ✓
