每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　2 对成键电子，2 对孤对电子
  2. W2　4 个

✏️ 练习

  1. 4.1　(6 分)
    CH₄ 正四面体 ✓；NH₃ 三角锥 ✓；H₂O V 形 ✓；CO₂ 直线形 ✓；BF₃ 平面三角形 ✓；SF₆ 八面体 ✓
  2. 4.2　(3 分)
    C=O 键有极性（ΔEN = 1,0） ✓；CO₂ 是直线形、对称的 ✓；两个键的极性方向相反、互相抵消，所以分子非极性 ✓
  3. 4.3　(4 分)
    N–H 和 B–F 键都有极性 ✓；NH₃ 是三角锥（有孤对电子），不对称 → 极性分子 ✓✓；BF₃ 是平面三角形，对称，极性抵消 → 非极性 ✓
  4. 4.4　(5 分)
    (a) H–C≡N，N 上一对孤对电子 ✓✓　(b) 直线形 ✓　(c) 极性 ✓：两端原子不同，C–H 与 C≡N 的极性不能抵消 ✓
