Day 25物理 P1答案与评分点共 20 分

每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　800 × 10−4 = 0,08 m2
  2. W2　cos 0° = 1；cos 90° = 0

✏️ 练习

  1. 25.1　(2 分)
    以导线为圆心的同心圆 ✓；方向顺时针 ✓
  2. 25.2　(7 分)
    (a) A = 0,2 × 0,3 = 0,06 m2 ✓
    (b) ΔΦ = ΔB·A cos0° ✓ = (1,2 − 0,4)(0,06)(1) ✓ = 0,048 Wb ✓
    (c) emf = NΔΦ/Δt = 200 × 0,048 / 0,5 ✓✓ = 19,2 V ✓
  3. 25.3　(3 分)
    A = 40 × 10−4 = 4 × 10−3 m2 ✓；Φ = 0,5 × 4 × 10−3 × cos0° = 2 × 10−3 Wb ✓；NΦ = 150 × 2 × 10−3 = 0,30 Wb ✓
  4. 25.4　(3 分)
    增加匝数 ✓；更快地移动磁铁或线圈（缩短 Δt） ✓；使用更强的磁场或更大的线圈面积 ✓
  5. 25.5　(5 分)
    Φ初 = 0,8 × 0,02 × cos0° = 0,016 Wb ✓；Φ末 = 0（cos90° = 0） ✓；ΔΦ = −0,016 Wb ✓；emf = −100 × (−0,016)/0,1 ✓ = 16 V ✓
