  2. W2　极性分子

✏️ 练习

  1. 6.1　(5 分)
    (a) London ✓　(b) 偶极-偶极 ✓　(c) 氢键 ✓　(d) 离子-偶极 ✓　(e) London ✓
  2. 6.2　(3 分)
    H 原子直接与 N、O 或 F 相连 ✓；另一分子上有 N、O 或 F 的孤对电子 ✓；N/O/F 原子小、电负性高 ✓
  3. 6.3　(3 分)
    分子内力：同一个 HCl 分子中 H 与 Cl 之间的共价键 ✓；分子间力：一个 HCl 分子与相邻 HCl 分子之间的偶极-偶极力 ✓；分子内力强得多 ✓
  4. 6.4　(3 分)
    Br2 ✓；Br2 的电子更多（分子更大），电子云更容易变形 ✓，瞬时偶极更强 ✓
  5. 6.5　(4 分)
    CO2 直线形、对称 ✓ → 非极性分子 → 只有 London 力 ✓；SO2 是 V 形、不对称 ✓ → 极性分子 → 有偶极-偶极力 ✓
