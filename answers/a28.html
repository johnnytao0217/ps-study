Day 28物理 P1答案与评分点共 20 分

每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　0 m·s⁻¹
  2. W2　v = 0 + 9,8 × 2 = 19,6 m·s⁻¹（向下）

✏️ 练习

  1. 28.1　(4 分)
    取向下为正。(a) Δx = uΔt + ½aΔt²：45 = 0 + ½(9,8)Δt² ✓ → Δt = 3,03 s ✓　(b) v = u + aΔt = 0 + 9,8 × 3,03 ✓ = 29,70 m·s⁻¹ ✓
  2. 28.2　(5 分)
    取向上为正。(a) 0 = 14,7 + (−9,8)Δt ✓ → Δt = 1,5 s ✓　(b) 0 = 14,7² + 2(−9,8)Δx ✓✓ → Δx = 11,03 m ✓
  3. 28.3　(2 分)
    v = 0 ✓；a = 9,8 m·s⁻² 竖直向下 ✓
  4. 28.4　(2 分)
    只有一个力：重力 w（或 Fg） ✓，竖直向下 ✓
  5. 28.5　(7 分)
    (a) g = Δv/Δt = 6/1,2 ✓ = 5 m·s⁻² ✓　(b) Δx = ½(5)(1,2)² = 3,6 m（或 v–t 图面积 ½ × 1,2 × 6） ✓✓
    (c) g = GM/r²，M 相同 → g ∝ 1/r² ✓；rX² / R² = 9,8/5 ✓ → rX = 1,40 R ✓
