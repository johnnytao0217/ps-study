Day 10化学 P2答案与评分点共 19 分

每个 ✓ 代表考试中的 1 分。核对时不只看最终答案：公式、代入、单位、方向都要有。

⏱ 热身

  1. W1　300 K
  2. W2　1 000 cm3

✏️ 练习

  1. 10.1　(3 分)
    p1V1 = p2V2 ✓；150 × 2 = p2 × 0,5 ✓ → p2 = 600 kPa ✓
  2. 10.2　(3 分)
    V1/T1 = V2/T2 ✓；3/300 = V2/400 ✓ → V2 = 4 dm3 ✓
  3. 10.3　(3 分)
    体积减小，分子之间、分子与器壁的距离变小 ✓；单位时间内碰撞器壁的次数增多 ✓；对器壁的作用力增大，所以压强增大 ✓
  4. 10.4　(3 分)
    p1/T1 = p2/T2 ✓；100/293 = p2/423 ✓ → p2 = 144,37 kPa ✓
  5. 10.5　(4 分)
    p1V1/T1 = p2V2/T2 ✓；(100)(250)/288 = (80)V2/318 ✓✓ → V2 = 345,05 cm3 ✓
  6. 10.6　(3 分)
    自变量：体积（或压强） ✓；因变量：压强（或体积） ✓；控制变量：温度和气体的量 ✓
