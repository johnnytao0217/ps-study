✏️ 练习

  1. 18.1　(3 分)
    M(NH₄NO₃) = 80 g·mol⁻¹ ✓；N 的质量 = 28 g ✓；28/80 × 100 = 35% ✓
  2. 18.2　(6 分)
    n(C) = 40/12 = 3,33 ✓；n(H) = 6,7/1 = 6,7 ✓；n(O) = 53,3/16 = 3,33 ✓；比值 1 : 2 : 1 → CH₂O ✓；经验式质量 30，180/30 = 6 ✓ → C₆H₁₂O₆ ✓
  3. 18.3　(5 分)
    H = 14,3% ✓；n(C) = 85,7/12 = 7,14，n(H) = 14,3 ✓；比 1 : 2 → CH₂ ✓；56/14 = 4 ✓ → C₄H₈ ✓
  4. 18.4　(5 分)
    m(H₂O) = 5,00 − 3,20 = 1,80 g ✓；n(H₂O) = 1,80/18 = 0,10 mol ✓；n(CuSO₄) = 3,20/159,5 = 0,020 mol ✓；x = 0,10/0,020 ✓ = 5 ✓
