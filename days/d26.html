📘 今日新知

楞次定律 Lenz's law：感应电流的方向，总是使它产生的磁场反对引起它的磁通变化。口诀“来拒去留”：磁铁 N 极靠近线圈 → 线圈这一端变成 N 极（排斥）；N 极离开 → 这一端变成 S 极（吸引）。

变压器只能用交流 AC：原线圈中的交流电使铁芯里的磁通不断变化 → 副线圈产生感应 emf。稳定的直流 DC 只在接通瞬间有变化，之后磁通不变 → 没有感应电流。理想变压器：Vs/Vp = Ns/Np；Ns > Np 为升压，反之为降压。

为什么 Eskom 用高压输电：输送功率 P = VI 一定时，电压升高 → 电流减小 → 输电线上的热损耗 P损 = I²R 大大减小。到用户附近再用降压变压器降压。

解释题四步模板：① 什么在变化（磁通？）→ ② 法拉第：产生感应 emf / 电流 → ③ 楞次：感应磁场方向反对这个变化 → ④ 结果（排斥、吸引、环跳起……）。每一步一句话，写完再停。

🧮 公式

VsVp = NsNpVpIp = VsIsP损 = I²R

Lenz’s Law · 楞次定律
The induced current flows in a direction so as to set up a magnetic field that opposes the change in magnetic flux that produced it.
Step-up transformer · 升压变压器
A transformer with more turns on the secondary coil than on the primary coil, so that the secondary voltage is greater than the primary voltage.
