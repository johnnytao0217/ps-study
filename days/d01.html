📘 今日新知

标量 scalar 只有大小（质量、时间、路程、速率、能量）；矢量 vector 既有大小又有方向（位移、速度、加速度、力、重力 weight）。

合矢量 resultant：能代替所有矢量共同作用效果的那一个矢量。求法：把矢量首尾相接 tip-to-tail，从第一个的尾指向最后一个的头。

两个矢量互相垂直时：大小用勾股定理，方向用 tan。两个力同向时相加、反向时相减，所以 15 N 和 7 N 的合力一定在 8 N 到 22 N 之间。

分解 resolve：一个斜向的力 F（与水平成 θ）可以拆成水平分量 F cosθ 和竖直分量 F sinθ。斜面、斜拉题全靠它。

📖 必背定义今天就背；反面练习时合上正面默写

Scalar · 标量
A physical quantity that has magnitude only.
Vector · 矢量
A physical quantity that has both magnitude and direction.
Resultant vector · 合矢量
The single vector that has the same effect as all the original vectors acting together.
